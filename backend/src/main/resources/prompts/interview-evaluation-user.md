## 评估要求
1. 根据全部问题与回答，对候选人做**综合评分**与**综合反馈**，而非逐题评分
2. 综合评分需综合技术准确性、完整性、深度与表达，并参考个人的岗位适配度
3. 综合反馈需具体指出候选人的整体优势、主要不足及提升方向，不可笼统评价
4. 参考答案基线仅用于校准深度与完整性，允许候选人使用等价但正确的不同表述
