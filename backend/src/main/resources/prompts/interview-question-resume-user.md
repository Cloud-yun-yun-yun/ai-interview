## 输出要求
- 必须只输出一个合法的 JSON 对象，不要输出任何解释、前后缀文字或 Markdown 代码块标记。
- 该 JSON 对象的最外层必须包含一个名为 questions 的数组，该数组必须恰好包含 6 个元素，不多不少。生成后请自检数量，不达标则修正后再输出。
- questionId 按顺序递增：第一个为 "1"，第二个为 "2"，第三个为 "3"，第四个为 "4"，第五个为 "5"，第六个为 "6"。
- questions 数组中每个元素必须且只能包含以下四个字段：
  - questionId：字符串，问题的唯一标识，本批次固定为 "1"、"2"、"3"、"4"、"5"、"6"。
  - questionContent：字符串，面试主问题的内容，需结合候选人简历中的项目经历，针对相关技术方向深入提问。
  - topicSummary：字符串，知识点摘要，不超过 10 个字，必须与 questionContent 的内容对应。
  - type：字符串，技术分类 key，全大写，必须是单个 key（如 JAVA、MYSQL、REDIS、SPRING 等），不得拼接多个值，需与问题内容的技术方向一致。
- 字段名必须严格使用 questionId、questionContent、topicSummary、type，大小写一致，不得增删字段、不得改名。
- 所有字符串必须使用双引号，JSON 必须可被标准 JSON 解析器解析。
